SpaceWhiteboard — 编辑器设计稿

PICO OS 6 · DefaultWindowContainer（平面）· 默认窗口 1280×800 dp · 阶段 1a 绘制核心 · 全部 2D UI 走 SpatialUI + PicoTheme，无 Material/Material3

待用户决定  工具栏放顶部（变体 A）还是左侧（变体 B）。两个变体内容完全一致，只有摆放不同。下面的推荐是 变体 B（左侧），理由见每个变体下方的说明。请从 A / B 中选一个；其余内容（配色取值、元素、文案）随本页一并确认。

本页 1px = 1dp。截图里画布上的笔迹/形状是示意内容，不是资源文件。

四、颜色 token 表（defaultColorScheme(...) 的确切取值）

固定配色，不使用 PicoTheme { } 的系统自适应默认方案 —— 工作区已两次复现「默认方案跑出来是没有主题色的通用浅色 UI」。manifest 设 materialbackground="0"，根布局自绘不透明 fillSecondary。

defaultColorScheme 参数色取值不透明度用途（本应用内唯一含义）
fillPrimary0xFF2F6BEA不透明选中态唯一高饱和块面：当前工具、当前形状、当前粗细的按钮底色；选中色板的外环；主按钮（导出 PNG）底色
fillSecondary0xFF101826不透明应用根背景（工具栏所在的整块底），也是画布视口中纸面之外的留白区。manifest materialbackground=0 后自绘的那层不透明底
fillTertiary0xFFF6F3EC不透明画布纸面（2400×1600 board 矩形）。全应用唯一的浅色大块面
fillLight0x26FFFFFF15% 白次级按钮/未选中工具按钮的底色；分组容器的浅底。压在 fillSecondary 上得到 ≈#2A3140
labelPrimary0xFFEDF1F7不透明深色 chrome 上的一级文字与图标：选中工具图标、按钮文字、对话框标题
labelPrimaryLight0xFF16202E不透明浅色面上的文字：纸面空态提示语。（角色语义＝“压在亮色填充上的深色字”，见 Overwinter 同名用法）
labelSecondary0xB8EDF1F772% 白未选中工具图标、缩放百分比、保存状态文案、对话框正文
labelTertiary0x7AEDF1F748% 白禁用不可用之外的弱化文字；分组标题（本期未使用，预留）
labelQuaternary0x4DEDF1F730% 白最弱一级；纸面点阵网格在深色侧的对照值（本期未使用，预留）
lightenHover0x14FFFFFF8% 白hover 提亮层（由 spatialHoverEffect 消费）；确认对话框卡面 = fillSecondary 之上叠这一层
lightenPressed0x24FFFFFF14% 白按下提亮层
error0xFFE5484D不透明清空按钮图标/文字；确认对话框的破坏性按钮底色；保存失败指示（点 + 文案）
alert0xFFE9A23B不透明保存中指示点
passable0xFF3DBE8B不透明已保存指示点
interaction0xFF6699FF不透明链接式文字（本期未使用，预留，避免落回 SDK 默认值）
dividerLine0x24FFFFFF14% 白工具栏分组之间的 1dp 分隔线；未选中色板色点的描边环

注：fillTertiary 在本应用里被指定为浅色纸面，与它在同工作区其它项目中「深色面上的半透明浅底」的常见用法相反。因此任何依赖 fillTertiary 默认取色的内置组件，都必须显式传 containerColor，不能靠默认值。这一条写进了截图验证清单。
